# Adaptive Electroformed 3D Power Topology Lite (AE3PT-Lite): First-Year Glossary

## Technical, Business, Safety, and Project Terms in Plain Language

> **Writing rule:** Spell out an acronym the first time it appears. Use the shortened form only after the reader has been told what it means.

**AE3PT-Lite** means **Adaptive Electroformed 3D Power Topology Lite**. It is the project-created name for this classroom demonstration.

---

## 1. Project Name

### AE3PT-Lite

**Adaptive Electroformed 3D Power Topology Lite.** A project-created name for the small teaching demonstration.

### BAB-CS

A name appearing in the original research-scale material. Its full expansion is not defined in the available project sources. It is not required for the classroom demonstration and must not be presented as a standard engineering term.

## 9. Project Codes and Identifiers

- **G0–G7:** project gates; G means Gate and the number is the sequence.
- **A01–A03:** straight-reference samples.
- **B01–B03:** material-saving samples.
- **C01–C03:** repair-ready samples.
- **DS18B20:** manufacturer part number for the digital temperature sensor; not an acronym.
- **ADS1115:** manufacturer part number for the Analog-to-Digital Converter; not an acronym.
- **USD:** United States dollars, used as the planning currency.

## 11. Plain-Language Writing Checklist

Before releasing a report:

1. expand each acronym on first use;
2. define every symbol below an equation;
3. include units in table headings and chart axes;
4. separate observation from interpretation;
5. distinguish classroom criteria from standards;
6. state what the project does not prove;
7. explain cost assumptions;
8. ask a non-engineering reader to summarize the project.
